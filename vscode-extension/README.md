# AiraLang Language Support for VS Code

Official Visual Studio Code extension for **AiraLang** — the modern systems, AI, and cybersecurity programming language created by **Adam Eehan (Founder & CEO, Aira Group of Technology)**.

## ✨ Features
* **Syntax Highlighting:** Complete token colorization for `.aira` files (`say`, `let`, `fn`, `import`, modules, operators, comments).
* **Language Configuration:** Auto-closing brackets, braces, strings, and `#` / `//` comment toggling.
* **Intelligent Snippets:** Instant scaffolding for `say`, `let`, `fn`, `import "ai"`, `import "system"`, and `import "android"`.

## 🚀 How to Install
Place this folder inside your VS Code extensions folder:
- **Windows:** `%USERPROFILE%\.vscode\extensions\adameehan.airalang-1.0.0`
- **Linux / Mac:** `~/.vscode/extensions/adameehan.airalang-1.0.0`
